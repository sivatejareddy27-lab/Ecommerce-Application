# ECommerce Application - Shopeasy

An Online Shopping Application built with Core Java (Console) and deployed as a Web Application using HTML, CSS, Bootstrap and JavaScript.

## Features
- View Available Products
- Add to Cart with Quantity Selection
- Remove from Cart
- View Cart
- Stock Management
- Total Bill Calculation
- Order Placement with Success Notification
- Input Validation

## Products Available
- Laptop - ₹50,000
- Mobile - ₹20,000
- Headphones - ₹30,000
- Tablets - ₹15,000

## Technologies Used
- Core Java (Console Version)
- HTML
- CSS
- JavaScript
- Bootstrap 5
